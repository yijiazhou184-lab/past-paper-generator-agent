# 首轮 MVP 与四轮开发验收方案

## 1. 目标与范围原则

依据现有 [PRD](PRD-v1.0.md)、[技术方案](technical-design-v0.2.md)和 [AI 方案](ai-technical-design-v0.1.md)，采用四轮交付。

**首轮证明：用户能从真实课程材料出发，得到可作答、可核对、可打印的新练习。** 后续逐步扩大能力，最终完成全部 P0。首轮通过不等于完整首版完成。

本轮仅确定范围、开发顺序和验收条件，不展开文件、接口字段、数据库结构或编码计划。

## 2. 首轮 MVP

**使用场景：本地单门 Quantitative Maths、一个明确章节、数字 PDF 输入。**

包含：

- 上传真实范围说明、章节教学资料及可用的试卷与官方解答，保留来源位置和必要公式、表格、图形。
- 展示可编辑的课程理解，经用户确认后使用。
- 支持 Foundation、Exam-standard、Challenge 三档难度及大题数调整；题型先限定为该章有依据支持的类型。
- 展示本次练习结构；配置变化影响结构时，重新确认。
- 真实生成新题、完整解答和评分点，执行结构、计算、语义及实质重复检查。
- 提供题卷、mark scheme 网页和两个独立 PDF；答案由用户主动打开。
- 保存确认版本、配置、任务与结果，支持刷新后找回；失败保留配置，PDF 重试沿用原题答。

首轮暂缓完整模拟卷、其他文件格式、多课程管理、材料更新合并、联网补充和受邀线上访问。必要的私有数据处理、版本绑定、运行限额和真实失败反馈从首轮保留。

**为什么先做：** 这条小闭环能同时检验材料理解、出题质量和最终交付，也便于定位错误来自哪个环节。

## 3. 四轮交付与退出条件

| 轮次 | 新增交付 | 如何检查、何时通过 |
|---|---|---|
| **第一轮：真实章节练习** | 上述 QM 小闭环 | 完成六次真实试跑；课程依据可核查，配置实际生效，题答完整，必要检查有证据，网页与两个 PDF 一致且可读；没有未解决的严重内容错误 |
| **第二轮：QM 完整模拟卷** | 完整模拟卷、多章节练习，以及相应的题型、分区、分值和必答／选答结构 | 至少完成一份真实完整卷及一份多章节练习；覆盖符合确认范围，结构与分值正确，长答案和必要素材齐备，长卷网页与 PDF 无关键排版缺陷；配置冲突不能被静默忽略 |
| **第三轮：完善本地产品** | 三门课程与全部规定格式；多课程管理、材料更新、版本差异、外部补充、历史去重、恢复、删除、反馈及备份 | 三门课程均有真实出卷证据，各格式实际进入解析链路；必要报表、图表和公式保留；更新不覆盖人工修改或旧卷；缺口处理、取消、重试、删除及备份恢复分别有通过证据 |
| **第四轮：受邀线上与正式验收** | 受邀账户、用户隔离、线上部署、配额与运行保障 | 全部 P0/AC 有验收记录；完成正式质量、性能和异常评测；跨用户访问被拒绝，支持恢复与删除；本地启动和线上使用均可复现，满足 PRD 发布条件后才标记首版完成 |

第三轮按三个验收面整理证据：**材料与课程、更新与证据、持续使用与恢复**，合并为一个开发轮次退出。

## 4. 验收方法、启动条件与默认约定

### 首轮六次真实试跑

提前冻结任务，安排：

- Exam-standard 同一主配置三次。
- Foundation、Challenge 各一次。
- Exam-standard 改变大题数一次。

检查配置效果、题答质量，以及与上传题、此前输出的实质重复。六次试跑用于早期验收，不据此宣称统计意义上的稳定性或难度校准已经完成。

### 内容与异常检查

- 从题目条件和课程方法复算适用计算；独立评估先看题目，再与生成答案比较。
- 来源同时检查“能定位”和“支持结论”。缺少官方细分评分时，明确标注建议评分。
- 首轮至少覆盖缺必要范围、关键内容不可读、无效结构、题答检查失败、单个 PDF 失败及刷新恢复。
- 缺答案、错对应、不可作答、严重计算错误或超纲要求未解决时，不能通过。
- 离线验收不增加学生逐卷人工审批步骤。

### 性能与正式评测

首轮允许在功能和内容通过后，带着明确的性能缺口继续迭代。课程分析和完整生成分别记录真实耗时；完整生成包含检查、网页与两个 PDF。超过 120 秒如实记为未达标，完整首版仍须满足 PRD 要求。

第三轮基线后冻结质量阈值及输入、负载和运行边界；第四轮执行 **18 个固定任务 × 每任务三次，共 54 个计划运行位置**。失败保留，补跑单列，不挑选最好结果替代完整报告。

### 首轮启动前需要具备

当前项目目录尚无真实课程样本。开始首轮前，需选定一个典型考试难度的 QM 章节，并准备：

- 明确当前考试范围、章节教学资料及可用参考解答。
- 人工核对的关键知识、方法、公式和来源清单。
- 经确认的练习规模、大题数支持范围及六次验收配置。
- 获准的外部处理服务与数据处理范围，以及试跑运行限额。

具体章节和数值依据真实材料冻结，不沿用原型中的固定题数、分值或时长。若资料暂不满足条件，先报告缺口，不使用模拟内容替代真实结果。
