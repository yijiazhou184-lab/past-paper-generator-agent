# 计算能力模块与 R5 核验缺口实施计划

用户已授权按多课程兼容方案的能力包边界改进数学核验，并允许有助于兼容化的通用接入修改。本次聚焦计算能力，课程选择多个能力包等完整机制另行实施。

## 结构与接口

- `backend/app/capabilities/symbolic/` 集中保存规格、表达式解析、符号执行、隔离进程、诊断与提示词片段。旧 generation 数学入口保留兼容导入。
- 通用题答 schema 组合该模块导出的核验类型。生成上下文装配能力说明，冻结版本及源文件／提示词哈希。读取旧结果继续使用保存快照，新运行要求新预检。
- 增加最大实数定义域、带符号的无穷极限、参数化多项式导数、参数分段全局最优核验。保留原 AST 的定义域约束，参数结论按完整区间证明。
- 参数最优首批支持一个参数、有限闭决策区间上的多项式目标，通过凸／凹性和一阶条件给出全局证书。无法完成证明时返回能力诊断，不能以抽样或省略检查宣称通过。
