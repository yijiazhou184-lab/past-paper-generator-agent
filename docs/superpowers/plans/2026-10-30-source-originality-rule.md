# 与课程材料比较的原创性规则调整

> 状态：**待用户确认的方案**（2026-10-30，Claude Code）。用户决定：与课程材料、历年卷比较时，允许“标准方法相同、题目不同”，只把“照搬原题”或“只换数字”判为重复。确认前不改代码。

## 起因

真实任务 `b02101f9` 只剩 1 项阻塞：`semantic:q3:originality`。q3c 使用了不同的函数，但解题路径（取对数 → 0/0 → 一次 L'Hôpital → 求值 → 取指数）与 M14 p4 的例子相同。按原规则（只换函数、照搬步骤也算重复），这项判 fail。用户决定放宽这条规则。

## 新规则

与课程材料、历年卷比较时，沿用卷内规则的两项事实和同样的定义：

- **题目**：题干给出的具体材料，只差数字或记号视为相同。
- **结论**：要求得出的结果种类。
- **只有题目和结论都相同才算重复**，这正好对应“照搬原题”和“只换数字”两种情况。
- 题目不同时，即使用的是同一个标准方法、同样的解题步骤，也可以接受。

这样，卷内比较和与课程材料比较使用**同一条规则**，只是比较对象不同。规则文件升为 `originality-policy-v2`，并在文件中保存用户这次决定的原文。

## 实现（与卷内规则同样的“判断与规则分离”）

1. **审阅只报告事实**：语义输出新增 `source_overlaps`。对候选题与提供的课程或历年卷摘录中相关的每一对，审阅报告：小问 ID、来源 ID、`same_stimulus` 及依据、两边各自的结论、`same_conclusion`。同样不设“是否重复”字段。
2. **由代码判定**：`semantic:qN:originality` 改由程序根据这些事实判定，题目和结论都相同则 fail，否则 pass。模型不再直接给出这一项的结论。
3. **防漏报**：每道题检索得分最高的 2 条比较摘录必须有事实记录，缺少则判 inconclusive。审阅缺失或不完整时判 not_checked。
4. **保留程序检查**：现有的“只换数字”文本比对（`local_duplicates` 中的 NUMBER_SWAP_DUPLICATE）不变，它本来就符合新规则。
5. **提示词**：`semantic_review.md` 和 `repair.md` 改写“与课程材料比较”的说明，只写通用定义，不放科目例子。`question_pairs.md` 原有“Do not copy source questions or just change numbers.”，已经符合新规则，**不改**。这样生成依据不变，可以继续复用已验证的大题。
6. **测试**：
   - 按事实判定：同材料同结论判 fail；同方法不同材料判 pass；只换数字（同材料）判 fail；
   - 防漏报：缺少高分摘录的事实判 inconclusive；
   - 分组审阅时，各组报告的事实都能汇总进来；
   - 修复只针对判 fail 的题；
   - 规则文件不含科目内容。
   - 评测样例补充若干“与课程材料比较”的条目，同样按跨科目、带标准答案的方式保存。

## 需要你确认的一点：标为 WRONG 的证明

你之前举过一个例子：沿用 seminar 那道 WRONG 证明的路径，算重复。按新规则，如果新题用的是不同的函数，只是借用“找出错误应用”的结构出一道新的找错题，就属于“方法相同、题目不同”，**会被接受**。照搬原来那道 WRONG 证明（同一题目）仍然算重复。

- **建议**：按新规则统一处理。新编的找错题本身就是课程方法的正常练习。
- **另一种做法**：把 WRONG 证明单独保留为例外，凡沿用其路径都算重复。但这需要在规则里加一条与具体材料相关的特殊规定，跟 AGENTS.md 第 3 节“不写死课程内容”的要求有冲突，需要改成由课程数据标注，工作量更大。

## 影响

- 版本升为 `review-policy-v3`、`originality-policy-v2`，语义 schema 有变化，context hash 会改变，需要新的预检和授权。
- 生成提示词和生成依据都不变，所以 b02101f9 已验证的第 0 轮大题（Q1–Q4）可以全部复用。下一次真实运行预计**不需要生成调用**，只做完整核验，必要时再做一轮修复。
- 风险：放宽之后，“方法相同、只换函数”的题会被接受，练习的新颖程度更依赖生成阶段的设计。这是用户已经接受的取舍。
