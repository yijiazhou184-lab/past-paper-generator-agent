## 新能力和证明范围

| 规格 | 检查内容及边界 |
|---|---|
| `maximal_domain` | 完整实数定义域与区间并集比较；保留原 AST 各子式限制和约分前孔洞；空列表表示空集 |
| `signed_limit` | 明确趋近区间、方向及正／负无穷，不将无穷当成普通数做差比较 |
| `parameter_identity` | 单参数多项式恒等式，或决策变量取指定数值时的参数表达式 |
| `parameter_derivative` | 对声明的决策变量或参数求一／二阶导，检查整个区间上的多项式恒等式 |
| `parameter_optimum` | 单参数、有限闭决策区间上的多项式目标；检查参数分支完整且不重叠、可行性、全局凸／凹性、一阶最优条件及最优值；声明唯一时另证唯一性 |

参数目标限制为总次数不超过 8、幂指数为 0–6 的整数，系数用有理数字面值。全局凸／凹性采用足够条件证书，不能证明的情形明确返回能力不足，不以数值采样宣称成立。保留原表达式复杂度限制及隔离子进程的单项超时。分数幂遵循现有主值语义，不充当负数上的实奇次根运算符，规格说明已明确该边界。

回归覆盖完整定义域、遗漏区间、约分孔洞、对数边界、复数中间式、分数与负幂限制、极限符号和趋近方向、参数导数／取值、参数分支阈值／重叠／缺口、错误最优点、唯一性，以及能力不足时继续阻断。合成测试使用多组不同参数，没有把 R5 或 QM 的事实写入产品实现和提示词。
